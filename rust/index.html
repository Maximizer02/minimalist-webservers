Hello from Rust!

This page is being served from a web server written in pure Rust. This is part of a small project for which I have written multiple, very minimalistic web servers in various languages. If you have any of the other ones currently running, you can access them from here:

  • Web server written in Bash
  • Web server written in C

But please be warned! This project was built on the idea of "How hard could it be to write a web server?" and not "How can I create the best and most secure web server to ever exist?". For all I know, there could be 100 very critical security flaws in there. Therefore, I strongly advise you to not use this in any kind of production environment!

If you want to play around with any of the web servers, the source code for them can be found here. The only things you need to use them are Docker with a basic understanding of how to use it and a shell like Bash. To serve your own customized content, just replace your chosen web server's "index.html" file with your own and rebuild the Docker image.
